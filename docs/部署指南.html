1. 方案选择矩阵

场景 推荐方案 核心优势 兼容性

2. 进阶：AWS (Lightsail) 部署建议

  • 地域建议：Singapore (ap-southeast-1) - 访问中亚站点速度极致。
  • 推荐规格：2 vCPUs, 4GB/8GB 内存 (Lightsail 性价比极高)。
  • 核心优势：顶级国际骨干网，IP 地址较为“纯净”，反爬穿透率更高。
  • 支付建议：需要 Visa/MasterCard 信用卡，适合有外币支付能力的企业。

3. 前期：本地电脑部署流程

  • 硬件建议：内存 16GB 以上，Windows 10/11。
  • 网络环境：开启全局代理模式，确保能访问 Kaspi 和 Algatop。
  • 环境安装： 
    pip install -r requirements.txt
playwright install chromium
  • 核心逻辑：
    1. 运行 launch_rpa_chrome.py 接管浏览器。
    2. 手动登录 Algatop 账号，保持标签页不关闭。
    3. 运行后端 start_backend.py 和前端 npm run dev。

3. 进阶：腾讯云服务器配置

  • 推荐地域：中国香港 (Hong Kong) - 跨境抓取核心。
  • 推荐配置：4核 8G 内存，5Mbps 带宽。
  • 系统选择：Windows Server 2019/2022 (方便 RDP 远程登录维护)。
  • 轻量级应用：优先购买腾讯云“轻量应用服务器 (Lighthouse)”，性价比最高。

4. 安全性与账号守护

为了保证账号寿命，请务必注意：

  • 采集速度：模拟真人，翻页间隔建议在 3-8 秒。
  • IP 一致性：尽量不要频繁在不同地域 IP 间切换登录。
  • 流量拦截：咱们采用的是被动监听流量包技术，原则上比 DOM 抓取更安全。
